# Spotify Genre Prediction using Machine Learning

## Project Overview
This project focuses on predicting the genre of Spotify songs using machine learning techniques. The objective is to compare multiple classification models and identify the best-performing approach for genre prediction.

## Dataset
The dataset contains Spotify song features such as:
- Danceability
- Energy
- Loudness
- Mode
- Tempo
- Acousticness
- Valence
- Liveness
- Instrumentalness
- Speechiness

## Project Workflow
1. Data loading and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Model training
5. Model evaluation and comparison
6. Selection of the best-performing model

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Models Evaluated
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- Support Vector Machine
- Extra Trees
- Gradient Boosting
- AdaBoost
- XGBoost
- LightGBM
- Neural Network (MLP)

## Results
Different machine learning models were compared based on their classification performance. The project identifies the model that achieves the highest accuracy in predicting song genres.
